# Portfolio Nafarie Hanif

Website portfolio pribadi sederhana yang dibuat sebagai latihan HTML dan CSS.

## Tentang proyek

Halaman ini berisi profil singkat, keahlian yang sedang dipelajari, perjalanan belajar, dan beberapa proyek latihan web.

## Teknologi

- HTML5
- CSS3
- Responsive design

## Menjalankan secara lokal

1. Buka file `index.html` di browser.
2. Halaman akan mengarahkan ke `studi-kasus-profile-styled.html`.

## Publikasi dengan GitHub Pages

1. Upload seluruh isi folder ini ke repository GitHub.
2. Buka **Settings** → **Pages** pada repository.
3. Pilih **Deploy from a branch**, lalu pilih branch `main` dan folder `/ (root)`.
4. Simpan. GitHub akan menyediakan alamat website setelah proses deployment selesai.
